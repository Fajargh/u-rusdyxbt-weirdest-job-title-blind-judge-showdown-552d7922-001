One job title, the weirdest we could think of: **Senior Vice President of Apologizing to Cats**.

A dead-serious corporate title for a gloriously unserious job — a senior executive whose entire portfolio is saying sorry to cats. It reads like a real job, it is specific enough to picture the person doing it, and the twist lands on the first read. The program writes exactly that title to `/output/entry.txt`, where the blind judge compares it two at a time against the other entries and picks the weirder, funnier one.

## Run it

```sh
python3 main.py
```
